# 나의 세계 · World Lab

여러 개의 독립된 세계를 만들고 시민과 문명의 변화를 관찰하는 모바일 우선 웹앱 프로토타입입니다.

## 현재 구현된 기능

- 세계 최대 10개 생성, 이름 변경, 삭제, 초기화, 복제
- 세계별 독립 데이터와 브라우저 자동 저장
- 세계 지도 화면과 세계·대륙·국가·도시·마을 확대 단계
- 시간 일시 정지와 1~100배속 조절
- 시민 추가, 시민 직업·성격·기술 숙련도 확인
- 중력, 평균 기온, 대기 산소 설정
- 지원되는 자연어 명령: 시민 추가, 마을 만들기, 과학 연구 시작, 시간 정지·재개
- 사건 연대기, 사건에 연결된 시민 반응, 긍정·부정·특이 필터
- 기술 발전과 조건 기반 도전과제
- 모바일 화면 레이아웃, 설치형 웹앱 메타데이터, 기본 오프라인 캐시

## GitHub Pages 켜기

1. 저장소의 **Settings**로 들어갑니다.
2. **Pages**를 선택합니다.
3. **Build and deployment**의 Source를 **Deploy from a branch**로 설정합니다.
4. Branch를 **main**, 폴더를 **/(root)**로 선택하고 Save를 누릅니다.
5. 배포가 끝나면 아래 주소에서 열 수 있습니다.

## 현재 버전의 한계

- 세계 데이터는 현재 기기의 브라우저 `localStorage`에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다.
- 실제 AI API나 서버는 연결되어 있지 않습니다. 자연어 입력은 앱 안에 구현한 규칙 기반 명령만 처리합니다.
- 물리·환경·인구·기술 발전은 기초 규칙 기반 모델입니다. 현실 역사 전체나 완전한 생태계·문명 시뮬레이션을 정확히 재현한다고 보장하지 않습니다.
- 화면을 열어 둔 동안에만 시뮬레이션 시간이 진행됩니다. 브라우저를 닫아 둔 동안 서버에서 세계가 진행되지는 않습니다.
- 지도는 현재 시뮬레이션 상태를 보여 주는 개념 지도이며 실제 지리 데이터를 사용하지 않습니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 반응형 디자인
- `script.js`: 시뮬레이션, 세계 관리, 저장 기능
- `manifest.json`, `icon.svg`: 설치형 웹앱 설정과 아이콘
- `sw.js`: 기본 캐시와 오프라인 처리
